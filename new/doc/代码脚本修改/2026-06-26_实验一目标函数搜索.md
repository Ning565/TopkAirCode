# 实验一目标函数搜索

## 修改文件

- `exp/experiment1_objective/run.py`
  - 新增实验一的独立脚本，输出 learning、channel、ADC surrogate 和总目标函数随 `k/d` 的变化。
  - 支持 `Top-k`、`Rand-k`、`Full update` 和 `ADC-unaware Top-k` 消融。
  - 对候选 `k` 计算 `b*(k)=min{B_P(k), B_epsilon(k)}`，再做一维搜索。
  - 内置趋势检查：学习项下降、通信/ADC 项上升、总目标 U 形、`Top-k k* < Rand-k k*`、ADC-unaware 选择更大的 `k`。
  - 删除自动调参逻辑，改为固定系统参数和目标函数权重后，对同一组候选 `k/d` 做一维扫描，`k*` 由 `argmin J(k)` 得到。

- `exp/experiment1_objective/run_experiment1.sh`
  - 新增实验一总运行脚本，不包含环境安装。
  - 日志写入 `exp/experiment1_objective/logs/`，结果写入 `exp/experiment1_objective/final/`。

- `exp/experiment1_objective/run_real_calibration.py`
  - 新增真实 calibration 版本。
  - 使用 FEMNIST/CNN client update 统计 `bar_omega_A(k)`、support overlap、`rho_A(k)`、真实 OFDM/IFFT/ADC clipping surrogate。
  - `Top-k` 和 `Rand-k` 在同一 `k/d` 网格上独立扫描，`Full update` 固定为 `k=d`。

- `exp/experiment1_objective/run_real_calibration.sh`
  - 新增真实 calibration 运行脚本，不包含环境安装。
  - 默认使用 `quenv/bin/python`，结果写入 `exp/experiment1_objective/final_real/`。

## 运行命令

```bash
bash exp/experiment1_objective/run_experiment1.sh
```

真实 calibration 版本：

```bash
bash exp/experiment1_objective/run_real_calibration.sh --device cuda:3 --calib-rounds 3
```
