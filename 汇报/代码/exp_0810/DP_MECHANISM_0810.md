# exp_0810 隐私机制变更说明（0810：人工噪声补足设计）

本说明记录 exp_0810 套件从"纯本征噪声 DP（b_t=min{B_ε,ex, B_P}）"切换为
"满功率 + 人工噪声补足 DP"的完整口径。**物理层（拓扑、路损、热噪声、OFDM、
过采样、AGC、径向限幅、双口径统计）一律不变**；变更只发生在缩放规则与噪声
构成上。两份场景文档（`汇报8.4/通信场景/*.md`）的隐私一节尚未同步，以本文
与代码为准，待后续统一修订。

## 1. 为什么改

旧规则在真实链路（250 m / 100 mW / −174 dBm/Hz / NF 5 dB）下，隐私/功率约束
切换点为 ε\* ≈ ρ²，ρ = 2·min|g|·√(SM·P_cap)/σ_sc ≈ 7×10⁴（dB 账：链路 35 dB +
突发能量累积 10log₁₀(SM)=56 dB + 6 dB ≈ 97 dB），即 ε\* ≈ 5×10⁹。ε ≤ 30 时
b 被压到热噪声下约 50 dB，AGC/削顶统计的全是接收机热噪声，PAPR-ADC 实验失效；
且 ε 量级不符合 TWC/JSAC/TIFS 文献（调研 §2.2 已判定 10⁸–10¹⁰ 不可用）。

## 2. 新机制（Koda'20 → Wei JSAC'22 → Liu TWC'24 谱系）

记 Δ(k)=2c_tx√k，margin(ε)=√(ε+ln(1/δ))−√(ln(1/δ))，N 客户端数，d 模型维度。
实验 0810 将 `c_tx` 声明为独立、公开且轮间固定的逐坐标门限，不由优化器当前
学习率反算；这避免学习率调度隐式改变无线功率和隐私机制。收敛附录中的
`ητC` 在本实验接口中统一替换为该公开 `c_tx`。

0811 首轮真实更新尺度审计后，基准值由 `0.02` 调整为 `0.01`。在
Top-k `k/d=0.001` 下，该调整将全向量噪声/有效信号范数比由约 88 降至约 63，
但已选坐标裁剪率由约 17% 升至约 59%；继续降至 `0.005` 时约 99% 的已选坐标
饱和且信噪比不再明显改善。因此 `0.01` 只是裁剪偏差与最坏情况 DP 噪声之间的
审慎折中，不代表全维人工补噪造成的收敛问题已经解决。

1. **功率满配（含噪声功率税）**：
   b_t = B_P^t(k)/√F，F = 1 + 2d/(N·margin²)。
   税因子来自人工噪声铺满全部 d 个网格坐标（Top-k 支持集私有，噪声只铺自身
   支持集会泄露支持集），其发射能量计入 P_cap。由于高斯噪声能量无界，人工
   噪声部分的功率约束是期望整轮平均功率口径；代码逐轮报告最差信道客户端的
   `expected_power_utilization`，不得把它表述成逐噪声实现的确定性峰值保证。
2. **客户端注噪（实轴、更新域、全网格）**：每客户端独立加 N(0, σ_a²)，
   σ_a² = max{0, Δ²(k)/margin² − σ_sc²/b_t²}/(2N)。
   全部为公开量（c_tx、k、N、ε、δ、σ_sc、广播的 b_t），客户端无需任何 CSI，
   信令零新增。热噪声抵扣项 σ_sc²/b_t² 即"免费隐私"额度；深衰落轮自动增大。
3. **DP 条件（实轴观测）**：(b_tΔ(k))² ≤ margin²·(σ_sc² + 2b_t²Nσ_a²)。
   σ_a 取上式时恰好取等，恢复后逐坐标 DP 噪声有信道无关闭式
   **σ_dp = Δ(k)/(√2·N·margin(ε))**。

## 3. 关键闭式与预期数字

- **宽松阈值（稀疏化换隐私的定量形态）**：σ_dp ≤ c_tx ⟺
  ε ≥ ε_loose(k) = (√(2k)/N + √ln(1/δ))² − ln(1/δ)。
  k=404 → ε_loose≈9.5；k=1000 → ε_loose≈16.8。**k\*∈[400,1000] 时
  "ε=10~15 即宽松"精确成立，环境参数零改动。**
- **本征免费区（诚实声明）**：σ_a=0 需要 margin·√F ≥ ρ；而 margin·√F 有
  与 ε 无关的下限 √(2d/N)≈201 ≪ ρ≈7×10⁴，故 ε≤30 时人工噪声恒开启。
  免费区不再作为卖点，只保留为协议完备性（代码报 `eps_free_intrinsic`）。
- **功率税**：√F(ε=5)≈346，√F(ε=30)≈82。补噪激活时 σ_dp 与 b 无关，
  但它直接进入收敛界的等效聚合噪声项，不能表述为“学习侧零影响”；缩小 b
  还会放大恢复后的热噪声。
- **波形结构可见性**：逐坐标信号/人工噪声幅度比 = N·margin/(2√k)。
  k=404：ε=5 时 0.41（噪声主导、波形高斯化），ε=30 时 1.71（结构可见）。
  PAPR/削顶随 ε 的变化是新的诚实实验轴（Tegin&Duman 假设高斯输入，我们在
  大 ε 端保留稀疏结构、小 ε 端自然高斯化）。

## 6. 0811 增补：锚点、χ 审计、协议决定与功率保证口径

本节回应《人工噪声补足机制对隐私功率与收敛性的影响.md》与
《汇报0807/整体场景.md》中留下的开放问题。

### 6.1 旧 SNR15 工作点锚定（已解决：0811 验证）

学习侧等价条件为 ρ_g ≡ g·√(SM·P_op)/σ_sc = h_th·√(d·SNR15) ≈ 357.3。
两条反算路径：

- 固定 P=20 dBm 反算距离 → 需 PL≈152 dB → r≈11.9 km，**不物理，否决**；
- 固定 r=250 m 反算工作功率 → **P_op≈−30.3 dBm**（上行开环功控，合法范围），
  此时新场景有效噪声 σ_sc/(√2·b·N)=4.870e-4 与旧代码逐位一致（已验证）。

实现：`PhyConfig.p_operating_dbm`（NaN=用 P_cap）+ `PhyConfig.dp_mode="off"`。
分步对齐流程（先通信确定，再 PAPR，再 DP）：
`--dp-mode off --p-operating-dbm -30.3` 应复现旧 exp2 精度曲线 → 确认后恢复
`--dp-mode topup` 逐档启用 ε。

### 6.2 χ 审计与协议决定（全 d 维补噪 vs noisy-vector-后-Top-k）

χ_A(k)=d·σ_dp²/E‖s̄‖² 在全 d 维补噪下有 k 无关下限 2d/(N²·margin²)
（ε=15 时 ≈479，√χ≈22～90 倍，对应 0811 审计实测的 88 倍），永远 ≫1。
**决定：保留全 d 维补噪协议**，理由：(i) Top-k 支持集私有，只铺自身支持集
会泄露支持集，全维高斯机制是唯一 DP-clean 的选择；(ii) 与 v8 固定完整资源
栅格口径一致；(iii) 旧实验三经验证明同结构可训（全 d 维噪声 σ=0.0055 训到
81%）——学习侧的操作性指标是逐坐标 σ_dp，不是 χ。noisy-vector-后-Top-k
（只发 k 维）作为已论证的替代方案保留在影响文档中，采纳需重写压缩算子/
保留系数/EF/功率分析，暂不实现。
落地：exp1 逐候选报告 `chi_dp`、`sigma_dp_over_update_rms`（基准 median
更新 RMS，0811 审计值 4.51e-4），summary 增“DP 绝对尺度可行性审计”表，
σ_dp>0.02（旧崩塌起点）标 COLLAPSE-RISK；不改变 k* 的选择规则。

### 6.3 randk/full “都差且差不多”的解释

σ_dp∝√k：ε=15、c_tx=0.01 下 randk@0.65→σ_dp≈0.18、full→≈0.22，均远超旧数据
崩塌线 0.05，故双双崩且难分；Top-k@k/d≤10⁻³→σ_dp≤0.007 落在可训区。
这是闭式必然，也正是稀疏化换隐私的卖点本身。

### 6.4 功率约束的高概率口径（已解决：Laurent–Massart 逐突发裕量）

高斯噪声能量无界，功率陈述为期望口径。实际发送能量是 ‖s_i+a_i‖²；给定
s_i 后，它按 σ_a² 归一化服从带非中心参数 ‖s_i‖²/σ_a² 的非中心卡方分布，
不能只用 ‖a_i‖² 的中心卡方波动代替（0812 review 指出的问题）。

**0812 解决方案**：用 Laurent–Massart 非中心卡方上尾界给出显式裕量。设
X=‖s+a‖²/σ_a² ~ χ²_d(λ)，λ=‖s‖²/σ_a²，则对 t>0：

P(X ≥ d+λ+2√((d+2λ)t)+2t) ≤ e^{−t}。

取最坏信号能量 ‖s‖²≤kc_tx²（对 λ 单调，故一致成立），定义相对裕量

M(t) = [2√((d+2λ̄)t)+2t]·σ_a² / (kc_tx²+dσ_a²)，λ̄=kc_tx²/σ_a²，t=ln(1/(1−conf))。

把功率预算折减 1/(1+M)（代码：b_star 在税后额外除以 √(1+M)），即得
**逐突发**保证 P(‖s+a‖² ≤ E‖s+a‖²·(1+M)) ≥ conf，对所有 ‖s‖²≤kc_tx² 的
实现一致成立；free region（σ_a=0）时 M=0，功率给定 s 后确定性成立。

**数值**：基线 d=404222、N=20、k/d=0.001、conf=1−10⁻⁶ 下
M ≈ 1.18%（且对 ε 不敏感：σ_a²∝Δ²/m² 使 λ̄=2N 恒定）；conf=1−10⁻¹²
时 M ≈ 1.67%。实测 `expected_power_utilization`≈0.98837 ≤ 1/(1+M)，
裕量恰好吸收尾部。DP 标定在折减后的 b 上计算，取等不变量不受影响
（数值验证 DP_lhs/rhs=0.9999999）。

代码：`PhyConfig.power_tail_conf`（默认 1−10⁻⁶）、`scaling_limits`
返回 `power_tail_margin`、CLI `--power-tail-conf`；`transmit_round` 新增
`realized_power_utilization_max`（逐突发最差客户端实测能量/预算）供审计。
论文侧：附录 remark A.2 与 v8 系统模型同步为“期望口径 + Laurent–Massart
裕量闭式”（不再声称中心卡方一句话即可）。
