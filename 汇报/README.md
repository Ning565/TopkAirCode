# Top-k AirComp-FL 阶段性实验汇报

本目录只保留当前可用于阶段汇报的实验 1-5：**6 张核心图、对应原始 CSV 和最小复现代码**。调参过程、训练日志、临时图和尚未迁移到统一场景的实验六均未放入。

## 一页结论

| 实验 | 核心问题 | 当前结果 |
|---|---|---|
| 实验一：离线一维搜索 | 理论目标能否给出合理的压缩率？ | ADC-aware Top-k 最优 `k/d=0.15`，Rand-k 最优 `k/d=0.50`；去掉 ADC 项后 Top-k 变为 `0.35`。 |
| 实验二：真实在线验证 | 离线工作点能否对应真实训练？ | 200 轮稳定工作点为 Top-k `0.12`、Rand-k `0.50`、Full `1.00`；后 25 轮均值为 `82.47%/75.78%/68.94%`。 |
| 实验二：收敛性 | Top-k 是否收敛更快？ | Top-k 在第 `45` 轮达到 `75%`，Rand-k 为第 `165` 轮，Full 在 200 轮内未达到；后段形成明显三级差距。 |
| 实验三：隐私强度 | 强隐私约束下 Top-k 是否更稳？ | `epsilon=1e5` 时 Top-k/Rand-k/Full 为 `20.67%/4.81%/2.88%`；约 `3e7` 后进入平台区，并回到实验二的准确率水平。 |
| 实验四：ADC 硬件压力 | 稀疏传输是否降低 ADC 总体负担？ | `gamma=1.3` 时资源加权 ADC 压力约为 `0.00373/0.01625/0.02500`，Top-k 比 Rand-k 和 Full 分别低约 `77%` 和 `85%`。 |
| 实验五：ADC-aware 消融 | 目标函数中的 ADC 项是否必要？ | `gamma=1.3` 时 ADC-aware Top-k 为 `81.25%`，ADC-unaware Top-k 为 `77.40%`，说明 ADC-aware 工作点选择带来 `3.85` 个百分点提升。 |

## 核心实验图

### 1. 离线目标函数与最优压缩率

蓝色学习误差随保留比例增加而下降，信道与 ADC 代价逐渐上升，总目标因此出现内部最优点。虚线对应 Top-k `0.15` 和 Rand-k `0.50`。

![实验一：离线目标函数与最优压缩率](图/01_实验一_离线目标函数与最优压缩率.png)

### 2. 在线压缩率验证

Top-k 与 Rand-k 均在共同压缩率网格 `0.10/0.12/0.15/0.20/0.35/0.50/0.65/0.80` 上真实训练 200 轮。Top-k 的 final 峰值在 `0.10`，后 25 轮稳定均值峰值在 `0.12`，因此收敛实验采用 `0.12`；Rand-k 稳定最优点为 `0.50`，与离线搜索一致。Full 没有可调压缩率，只在 `k/d=1` 显示一个真实训练点。

![实验二：压缩率与最终准确率](图/02_实验二_压缩率与最终准确率.png)

### 3. 通信轮数与准确率

图中只连接每 5 轮得到的真实评估点，不插值补造训练数据。Top-k 在第 45 轮达到 75%，Rand-k 在第 165 轮达到，Full 在 200 轮内未达到。后 25 轮均值分别为 `82.47%/75.78%/68.94%`。

![实验二：通信轮数与准确率](图/03_实验二_通信轮数与准确率.png)

### 4. 隐私预算与准确率

隐私预算较小时，隐私噪声占主导，Top-k 的低维传输优势最明显；预算放宽后，三种方法进入由收敛和功率约束主导的平台区。

![实验三：隐私预算与准确率](图/04_实验三_隐私预算与准确率.png)

### 5. ADC 硬件压力

这里报告的是 `实测 ADC NMSE x 有效传输坐标比例`。原始 PAPR/ADC NMSE 在 AGC 下可能接近，但 Top-k 只传输更小的有效维度，因此总体硬件误差负担明显更低。

![实验四：ADC 硬件压力](图/05_实验四_ADC硬件压力.png)

### 6. ADC-aware 稀疏率选择消融

ADC-aware Top-k 使用 `k/d=0.15`，ADC-unaware Top-k 使用去掉 ADC 项后得到的 `0.35`。前者在整个 gamma 扫描中均保持最高准确率。

![实验五：ADC 感知消融](图/06_实验五_ADC感知消融.png)

## 数据与代码

- `结果数据/`：上述每张图对应的原始 CSV，包含离线目标、在线 sweep、逐轮准确率、隐私 sweep、ADC 压力和消融结果。

## 汇报边界

- 当前正式结果均为固定随机种子 `2026` 的真实训练结果。它们适合阶段汇报，但论文最终统计仍需补充多随机种子均值和误差条。
- 实验一使用 calibration 场景：`epsilon=1e10, sigma0=0.01, Pmax=1e6, gamma=1.5`；更新后的实验二采用功率受限场景 `epsilon=3e8, sigma0=0.03, Pmax=1000, gamma=1.2`。Top-k 在线稳定点 `0.12` 接近离线粗网格点 `0.15`，Rand-k 均为 `0.50`；论文终稿前仍应在统一参数下重跑实验一。
- 当前实验三至六仍来自旧场景 `Pmax=2500, gamma=1.3`，不能与更新后的实验二宣称为完全统一参数结果；下一步需要按新场景重跑后再作为终稿实验组。
- 实验四不应表述为“Top-k 在相同 k 下必然降低原始 PAPR”，可支持的结论是：在各方法自己的最优工作点上，Top-k 显著降低资源加权 ADC 硬件压力。
- 实验六已有单种子原始结果，但尚未迁移到新的功率受限统一场景，因此暂未加入本汇报目录。
