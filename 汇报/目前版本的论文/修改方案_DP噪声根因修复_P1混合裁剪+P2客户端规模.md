## 0. 问题陈述（审计结论，全部有实测/原文依据）

1. **最优压缩率荒谬**：当前 exp1 在 ε=15 下把 k\* 压到 k/d=0.001（网格边界）；
   PFELS 原文实测最优 **p\*=0.3 (CIFAR-10) / p\*=0.5 (FEMNIST)**，相差 300~500 倍。
2. **噪声绝对尺度失控**：基线（ε=15/轮、δ=1e-3、N=20、k/d=0.001、d=404222）
   σ_dp=6.9e-3，是 0811 审计的逐坐标更新 RMS（4.51e-4）的 **15 倍**；
   MNIST 冒烟 NMSE≈4000，24 轮仅 30%（"能学"但远谈不上收敛良好）。
3. **逐坐标裁剪饱和**：c_tx=0.01 时 59% 已选坐标被削平——有偏畸变，
   且饱和后 SNR 不随 c_tx 改善（0811 审计表已证）。
4. **接收端去噪无效**：0812 实测 top-m 截断在 ε=15 基线上卡死 ~10%（对照 30%），
   幅度排序被噪声主导（逐坐标 SNR≈0.1）→ 已实现为条件选项、默认关闭。

**结论**：以上四条是同一个根因的四个症状——我们用文献中最难的 DP 粒度配了
文献中最小的客户端数和最坏情形的敏感度口径，把恢复噪声抬高了 50~100 倍。

## 1. 根因：与主流文献的四个参数级差距（证据全部来自论文原文）

| | PFELS (TDSC'24) | Liu (TWC'24) | Wei (JSAC'22) | 我们 (exp_0810) |
|---|---|---|---|---|
| DP 粒度 | client-level | **sample-level**（"adjacent datasets differ only one training sample"） | user-level + 数据子采样 | **client-level replace-one（最难）** |
| 客户端规模 | **N=1000 总数，每轮抽 r=32** | M=10 | ~50–100 | **N=20 全参与** |
| 抽样放大 | ε=log(1+(e^ε₀−1)r/N)，δ=1/N | 不需要 | 有（q_i） | **无** |
| 裁剪方式 | **整向量 L2 裁剪 C₁**（网格 {1,4,8,10} 调参） | 梯度范数有界 | L2 范数裁剪 C | **逐坐标 L∞ 裁剪 c_tx，Δ=2c_tx√k（最坏情形）** |
| 敏感度随 k | **与 k 无关** | — | — | **∝√k（σ_dp²∝k）** |
| 最优压缩率 | **0.3 / 0.5** | 不压缩 | 不压缩 | 0.001（被逼到边界） |

定量账（基线 m(ε)=2.05）：

- **G1 client-level + N=20**：σ_dp=√2·c_tx√k/(N·m)=6.9e-3=15×update RMS。
  client-level DP 文献全部靠大 population（N≥1000）支撑；N=20 无先例。
- **G2 敏感度 Δ(k)=2c_tx√k 随 k 增长**：σ_dp²∝k 且噪声项带 d·k 乘子，
  把 exp1 目标中的噪声项推向小 k，k\* 被压到网格边界——这是 k\*=0.001 的直接成因。
  PFELS 的 L2 敏感度与 k 无关，压缩误差随 p 降、隐私误差只温和增，交点才落在 0.3~0.5。
- **G3 逐坐标硬裁剪**：59% 饱和 = 有偏方向畸变 + SNR 改善通道堵死。
- **G4 d 维噪声 × k 维信号**：能量失配 d/k=1000 倍（影响文档 §2）；
  注意 G1+G2 修好后 σ_dp 降到信号量级，此项杀伤力自动降一个数量级。

## 2. P1｜混合裁剪敏感度（修 k\* 位置 + 消饱和偏差）

### 2.1 协议

客户端对稀疏化后的更新做**整向量 L2 裁剪**（与 Top-k 复合，标准两投影串联）：

```text
s_i(k) = Clip_L2( Top-k / Rand-k 稀疏化( delta_i + memory_i ),  C2 )
```

- `C2` 为公开常数，按真实 top-k 范数分布校准（PFELS 的 C₁ 网格调参同款）；
- `c_tx` 保留，语义收窄为**波形/PAPR/动态范围账的逐坐标界**（E_clip 链、
  峰值应力引理的输入不动），不再兼任隐私敏感度的唯一来源；
- **敏感度取两界之较小者**（两个投影复合的标准界）：

```text
Delta(k) = 2 * min( c_tx * sqrt(k),  C2 )
```

- 小 k 区 √k 支活跃 → **"稀疏化换隐私"卖点原样保留**；
  k > (C2/c_tx)² 后敏感度封顶 2C2 → σ_dp 不再随 k 增长 → 噪声项在 k 上变平 →
  **k\* 由保留能量/PAPR/ADC 项决定，回到内点**（这正是 ADC-aware 故事应在的位置）。
- L2 缩放替代逐坐标削平：59% 饱和偏差归零；功率账 ‖s‖²≤min(kc_tx², C2²) 反而更紧。

## 3. P2｜客户端规模 N: 20 → 100（修噪声 floor）

### 3.1 协议

参与客户端 N=100，全参与口径**不变**（理论零改动）。
σ_dp∝1/N → **噪声 floor 直接 ÷5**：6.9e-3 → 1.4e-3 ≈ 3×update RMS，
进入 PFELS 的工作量级。文献依据：client-level DP 需大 population（PFELS N=1000/r=32；
McMahan'18）；FEMNIST 有 3550 个真实用户，250 m 小区服务 100 UE 物理现实。

### 3.3 P2+（可选第二步）：抽样放大

总 population 1000、每轮均匀抽 r=100 + 放大引理 ε=log(1+(e^ε₀−1)r/N)
（PFELS Thm 2–3 同款）。诚实提醒：ε=15 时精确放大收益仅 ~1.2 倍；
价值在于**诚实报告更小的 ε**（同噪声水平可报 ε≈5）。需新增收敛附录的
采样方差项与部分参与 EF，改动中等——**建议 P1+P2 出结果后再评估**。

### 3.4 验收判据（P2）

1. σ_dp/update_RMS ≤ 5（目标 ~3）；
2. MNIST/FEMNIST 冒烟收敛速度显著加快，准确率向无噪 top-k 基线靠拢；
3. exp3 cross_check 在 N=100 下通过。

## 7. 风险与诚实声明

- **P1 的 C₂ 校准决定上限**：若真实 top-k 范数本身接近 c_tx√k（q95≈饱和上界），
  hybrid 收益小，需回到审计数据决策（审计步骤正是为此）；
- **P2 改 N 会牵动场景叙事**（小区用户数、Dirichlet 划分、计算时长 ×5），
  冒烟先跑 MNIST；
- **ε 口径不变**：仍是逐轮 client-level (ε,δ)、不声明 T 轮组合（Wei 同款先例）；
- 本方案不推翻 0811/0812 已落地的任何数学结论，只替换敏感度的参数化口径
  与客户端规模两个实验级决策。
