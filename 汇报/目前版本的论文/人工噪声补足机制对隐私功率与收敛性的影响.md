# 人工噪声补足机制对隐私、功率与收敛性的影响

## 结论

人工噪声补足不要求推翻现有收敛证明框架，但不能从收敛分析中省略。若人工噪声在聚合后仍表现为独立零均值高斯误差，现有证明中的信道噪声项应替换为“热噪声 + 人工噪声”的等效方差；若先形成完整维度的 DP 高斯输出、再对 noisy vector 执行 Top-k，则 Top-k 本身变成随机后处理，原有确定性 Top-k 保留系数也需要重新校准或证明。

PFELS 不注入人工噪声，而是使用接收端信道噪声提供内生隐私。PFELS 的非凸收敛界仍显式包含信道噪声项，并且其公共 Rand-k 投影输出为 k 维。本文计划采用人工噪声补足时，可以复用其“学习误差 + 聚合噪声”的证明结构，但不能直接复用其噪声维度、功率模型和数值结论。

## 当前代码与“只发射 k 维噪声”的区别

当前 `exp_0810` 的顺序是：

1. 对每个客户端更新执行 Top-k 或 Rand-k；
2. 将得到的稀疏向量映射到固定的完整 d 维 OFDM 资源栅格；
3. 在聚合等效实现中加入 `N(0,N sigma_a^2 I_d)`；
4. 发送并恢复完整 d 维向量。

因此，当前实现虽然有效更新每客户端最多只有 k 个非零坐标，但人工噪声覆盖全部 d 个坐标，噪声能量和功率税按 d 计算，不能称为“只发射 k 维噪声”。这也与当前 `v8.tex` 中“稀疏化不缩短完整资源栅格”的物理口径一致。

如果只在私有 Top-k 支持上加噪并发送这些坐标，未选择坐标恒为零，而相邻数据集可能产生不同支持。观察者可从零坐标与连续噪声坐标的差异识别支持，两个输出分布可能没有共同支撑，普通全维高斯机制的 DP 证明不能直接使用。公共、数据无关的 Rand-k 支持不存在这一问题，因此 PFELS 可以在公共 k 维投影中分析噪声。

一种严格可行但算法不同的“实际只发射 k 维”方案是：先构造敏感度受控的 d 维稀疏查询，对全部 d 维加入高斯噪声，再把 noisy vector 做 Top-k 并仅发送最终 k 个值及索引。最后一步属于 DP 后处理，不降低已经得到的隐私保证，实际发射能量也只来自最终 k 个坐标。但此时最终支持由噪声共同决定，不再等于原始更新的 Top-k；保留能量、误差反馈、功率上界和收敛系数都需按这个随机机制重新分析。当前代码尚未实现该方案。

## 等效噪声如何进入收敛分析

设每个客户端加入独立更新域人工噪声 `a_i ~ N(0,sigma_a^2 I_d)`，接收端实轴热噪声为 `n_R ~ N(0,sigma_sc^2/2 I_d)`。忽略动态范围非线性时，恢复误差为

```text
e_noise^t = (1/N) sum_i a_i^t + n_R^t/(b_t N),
```

其逐坐标方差为

```text
sigma_eff,t^2 = sigma_a,t^2/N + sigma_sc^2/(2 b_t^2 N^2).
```

因此现有收敛界中的热噪声能量项应由

```text
d sigma_sc^2/(2 b_t^2 N^2)
```

替换为

```text
d [sigma_a,t^2/N + sigma_sc^2/(2 b_t^2 N^2)].
```

若能严格证明输出只位于同一个公开 k 维子空间，则上式的 d 可替换为 k；私有、数据相关 Top-k 支持不能直接作此替换。人工噪声仍是独立零均值时，现有光滑性下降证明、局部 SGD 漂移和误差反馈递推的主体结构不变，变化集中在等效噪声二阶矩及其系数。

当前补噪取值满足

```text
sigma_a,t^2 = max{0, Delta(k)^2/margin^2 - sigma_sc^2/b_t^2}/(2N),
Delta(k) = 2 c_tx sqrt(k).
```

补噪激活且热噪声抵扣未截断时，恢复后的标准差化简为

```text
sigma_DP = Delta(k)/(sqrt(2) N margin).
```

这说明 `b_t` 在恢复后同时从有效信号和人工噪声中抵消。降低 `b_t` 是为了容纳人工噪声发射功率，并不会降低恢复后的人工噪声；相反，它会增大恢复后的热噪声。因此“同时调整功率缩放”不能自动抵消人工补噪造成的收敛损失。

## 功率约束的变化

当前全 d 维补噪的客户端期望整轮功率包含

```text
b_t^2 [k c_tx^2 + d sigma_a,t^2]/(SM |g_i^t|^2).
```

由此出现功率税 `F = 1 + 2d/(N margin^2)`，当前参数下 `sqrt(F)` 约为 98。高斯噪声能量无界，所以这只是期望平均功率约束；若论文需要逐轮高概率功率保证，应额外给出卡方尾界或发射端范数裁剪规则。

若改成 noisy vector 再 Top-k 并只发射 k 个坐标，功率项不再简单等于 `d sigma_a^2`，而是噪声与信号共同参与 Top-k 后的次序统计量，需要新的期望或高概率功率上界。

## c_tx 尺度审计与 0811 基准

FEMNIST 首轮审计得到完整平均更新 RMS 为 `4.51e-4`。在 `epsilon=15`、`N=20`、`k/d=0.001` 时，原 `c_tx=0.02` 对应 `sigma_DP=1.385e-2`，全向量噪声范数约为 Top-k 有效聚合信号的 88 倍。

扫描结果显示：

| c_tx | Top-k 0.001 已选坐标裁剪率 | 全向量噪声/信号范数 |
|---:|---:|---:|
| 0.020 | 17% | 88 |
| 0.010 | 59% | 63 |
| 0.005 | 99% | 59 |
| 0.001 | 100% | 59 |

因此继续减小门限会同时缩小有效信号和敏感度；当已选坐标全部饱和后，二者近似同比缩放，SNR 不再改善。0811 将独立公开基准暂定为 `c_tx=0.01`，它是裁剪偏差与 DP 噪声之间的折中，不是最终最优值，也不能单独解决全 d 维补噪问题。

## 对实验一离线搜索的影响

实验一已经把人工噪声加入等效高斯噪声统计，但当前校准分数主要对不同 k 的统计量做方法内归一化，没有直接约束噪声相对真实有效更新的绝对尺度。这会允许 Top-k `k/d=0.20` 这类保留能量高、但实际噪声范数远大于更新范数的候选被选中。

后续离线目标至少应显式报告而不是隐藏以下无量纲量：

```text
chi_A(k) = d sigma_DP(k)^2 / E ||(1/N) sum_i s_A,i(k)||_2^2,
```

公开 k 维噪声机制才可将分子中的 d 换成 k。`chi_A(k)` 应作为可行性门槛或具有固定物理含义的惩罚项，不能再通过每种方法内部的 min-max 归一化消除绝对量级。正式修改离线目标前，应先确定最终采用“完整 d 维补噪”还是“noisy vector 后处理 Top-k”的协议。

## 与现有论文内容的关系

当前 `v8.tex` 和 `convergence_analysis.tex` 描述的是内生信道噪声方案。加入人工补噪后，至少需要同步：

- 系统模型中的发送信号、噪声注入顺序和公开/私有支持定义；
- 功率约束是期望保证还是高概率保证；
- 隐私定理中的总高斯协方差与威胁模型；
- 收敛定理中的等效噪声二阶矩；
- 若采用 noisy vector 后处理 Top-k，重新定义随机压缩算子、保留系数和误差反馈。

只要最终仍将人工噪声建模为独立零均值聚合误差，收敛证明的总体分解可以保留；但其方差、维度和由功率缩放引起的数值项必须明确出现，不能仅在实验代码中隐式加入。
